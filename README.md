# بيانات تطبيق «أدوات الذكاء»

هذا المستودع يحوي البيانات الحية لتطبيق أندرويد «أدوات الذكاء» (دليل عربي لأدوات الذكاء الاصطناعي).

- `data.json`: ملف واحد بالشكل `{tools: [...], videos: {...}, built}` يجلبه التطبيق عند الفتح وعند التحديث.
- الرابط المباشر: https://raw.githubusercontent.com/smsmamaty10-code/adawat-ai-data/main/data.json
- يُحدَّث بالسكربت `scripts/publish-data.sh` في مستودع التطبيق. الأسعار تقريبية؛ راجِع الموقع الرسمي دائمًا.
